# 예약 트리거(Routine) 지시문

아래 내용을 `create_trigger`의 prompt로 사용한다. 매일 08:00 KST 실행 (9시 발행을 위해 검토 시간 확보).

---

E-blog 리포지토리(osy85759912/e-blog, 브랜치 claude/us-market-blog-automation-ke4cp6)의 자동화를 실행한다.

1. 웹 검색으로 지난 밤(미국 동부시간 기준 정규장~애프터마켓) 미국 증시 주요 이슈/가십을 조사한다. 단순 지수 등락이 아니라 화제성 있는 사건 하나를 고른다 (실적 쇼크, CEO 발언 논란, 급등락 종목, 소셜에서 화제된 종목 등).
2. `docs/style_guide.md`를 읽고 그 톤/구조/디스클레이머 규칙을 그대로 따라 글을 작성한다. 제목은 스타일 가이드의 클릭률 공식을 적용한다.
3. 이번 사건의 핵심 종목/섹터 티커 1~3개를 정한다.
4. `python scripts/generate_chart.py --tickers <티커들> --period 6mo --out /tmp/chart.png` 실행해 차트를 생성한다.
5. 본문 HTML을 파일로 저장한 뒤 `python scripts/publish_wordpress.py --title "<제목>" --content-file <path> --image /tmp/chart.png` 로 워드프레스에 **초안(draft)** 업로드한다. (WP_SITE_URL/WP_USERNAME/WP_APP_PASSWORD 환경변수가 없으면 이 단계에서 실패한다 — 그 경우 사용자에게 아직 워드프레스 연동이 안 되어 있다고만 알리고 종료한다.)
6. 업로드 성공 시, 푸시 알림으로 사용자에게 알린다: 글 제목, 한 줄 요약, 워드프레스 관리자 편집 링크. "검토 후 발행 버튼을 눌러주세요"라고 안내한다.
7. 매일 같은 종목/섹터가 반복되지 않도록, 전날 다룬 주제와 겹치면 다른 각도(다른 종목/다른 이슈)를 우선한다.

절대 하지 말 것:
- 검색으로 확인 안 된 수치·발언·인용을 지어내지 않는다.
- "매수/매도 추천" 같은 명시적 매매 지시 문구를 쓰지 않는다 (스타일 가이드의 의견 표현으로 대체).
- 초안을 published 상태로 직접 발행하지 않는다 — 항상 draft로 남기고 사람 확인을 거친다.
