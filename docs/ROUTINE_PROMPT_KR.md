# 국내장 예약 트리거(Routine) 지시문

아래 내용을 `create_trigger`의 prompt로 사용한다. 매일 17:00 KST 실행 (정규장 마감 15:30 이후 이슈 정리 시간 확보).

미국장용(`docs/ROUTINE_PROMPT.md`)과 구조는 동일하되, 대상 시장과 카테고리만 다르다.

---

E-blog 리포지토리(osy85759912/e-blog, 브랜치 claude/us-market-blog-automation-ke4cp6)의 국내장 자동화를 실행한다.

이 환경은 네트워크가 제한되어 있어 워드프레스 API나 주가 데이터에 직접 접근할 수 없다. 그래서 초안 작성까지만 하고, 실제 차트 생성·워드프레스 업로드는 GitHub Actions가 처리한다.

0. 시작 전에 `git pull --rebase origin claude/us-market-blog-automation-ke4cp6` 먼저 받는다 (다른 자동화나 GitHub Actions가 먼저 커밋했을 수 있어서, 안 받고 바로 푸시하면 거부된다).
1. 웹 검색으로 오늘 국내 증시(코스피/코스닥) 정규장 이슈를 조사한다. 단순 지수 등락이 아니라 화제성 있는 사건 하나를 고른다 (실적, 공시, 급등락 종목, 정책 이슈 등).
2. `docs/style_guide.md`의 톤/구조/디스클레이머 규칙을 그대로 따르되, 훅 문단은 "새벽 미국장" 대신 "오늘 국내장"으로 프레이밍한다 (예: "오늘 장 보다가...").
3. 핵심 종목/섹터 티커 1~3개를 정한다. 국내 종목은 야후 파이낸스 형식(`005930.KS`처럼 종목코드+`.KS`(코스피)/`.KQ`(코스닥))으로 적는다.
4. `pending/kr-<YYYY-MM-DD>.md` 파일을 아래 형식으로 작성한다 (파일명이 미국장용과 겹치지 않도록 `kr-` 접두사 필수):
   ```
   ---
   title: <제목>
   category: 국내주식
   tickers: <005930.KS 형식 티커>
   thumbnail_person: <핵심 인물 실명, 있으면>
   mood: <호재|악재|패닉|중립>
   ---
   <본문 HTML>
   ```
   `category: 국내주식`은 반드시 명시한다 (안 쓰면 기본값인 미국주식으로 잘못 들어간다). `mood`도 필수 — 대표이미지 배경색이 이 값에 따라 자동으로 바뀐다 (`docs/style_guide.md`의 "분위기 태그" 참고).
5. git add/commit/push 한다. 이 푸시가 GitHub Actions를 트리거해서 대표이미지·차트 생성 + 워드프레스 발행(즉시 publish, 초안 아님)을 처리한다.
6. 푸시 직후 (Actions 완료를 기다리지 않고) 사용자에게 푸시 알림을 보낸다: 글 제목, 한 줄 요약, "1~2분 후 블로그에 바로 발행됩니다." (컨펌 절차 없이 바로 발행되므로 발행 버튼을 눌러달라는 안내는 하지 않는다.)
7. 전날과 같은 종목/섹터가 반복되면 다른 각도를 우선한다.

절대 하지 말 것:
- 확인 안 된 수치·발언·인용을 지어내지 않는다.
- "매수/매도 추천" 같은 명시적 매매 지시 문구를 쓰지 않는다.
- 이 환경에서 직접 워드프레스 API나 주가 API를 호출하려고 시도하지 않는다 — 반드시 `pending/`에 파일을 커밋하는 방식으로만 처리한다.
- `category`를 빠뜨리지 않는다 (미국주식용과 카테고리가 다르다).
